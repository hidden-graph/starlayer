# starlayer

RDF 1.2, SPARQL 1.2 and SHACL 1.2 for Python, over Oxigraph (pyoxigraph): graphs with triple terms, reifiers, annotations and direction-tagged literals, SPARQL 1.2 queries and rules (SRL), and a native SHACL 1.2 engine with rules, node expressions and UI widget selection.

    pip install starlayer

The project README, the guides and the design notes are in the repository: <https://github.com/hidden-graph/starlayer>.
