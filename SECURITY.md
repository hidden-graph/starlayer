# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in StarLayer, please report it privately and responsibly.

Please do not open a public GitHub issue for security-sensitive reports.

Send the details to the maintainers through the repository's private reporting path or by contacting the project owner directly via the repository's available contact information.

## Response expectations

We will do our best to acknowledge reports promptly and work to assess, reproduce, and fix the issue as quickly as possible.

## Scope

This policy applies to the repository code and packaged releases in this project.
